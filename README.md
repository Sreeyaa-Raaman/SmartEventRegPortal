# Smart Event Registration Portal

## Objective
The Smart Event Registration Portal is a modern web application designed to simplify the process of managing events and participant registrations. The platform allows users to browse upcoming events, register online, and receive confirmation details. Additionally, administrators can efficiently manage event data and participant records through a dedicated dashboard.

## Features
- **Event Discovery**: Browse upcoming events with details like date, time, location, and description.
- **Participant Registration**: Easy-to-use registration forms for users to sign up for events.
- **QR Code Tickets**: Automatically generated QR code-based tickets upon successful registration.
- **Admin Dashboard**: Dedicated management area for administrators to view events, track registrations, and manage participants.
- **CSV Export**: Export participant data to CSV for external reporting and management.
- **Dark Mode Support**: Seamless toggle between light and dark themes for better user experience.
- **Responsive Design**: fully responsive design that looks great on mobile, tablet, and desktop devices.
- **Authentication**: Secure (mock) authentication for users and administrators.

## Tech Stack
- **Frontend**: React (Vite)
- **Styling**: Vanilla CSS with CSS Variables for Dark Mode
- **Routing**: React Router DOM
- **Icons**: Lucide React
- **QR Code Generation**: qrcode.react
- **Date Formatting**: date-fns

## Setup Instructions
1. **Clone the repository** (if applicable) or navigate to the project directory.
2. **Install dependencies**:
   ```bash
   npm install
   ```
3. **Start the development server**:
   ```bash
   npm run dev
   ```
4. **Access the application** in your browser at `http://localhost:5173`.
